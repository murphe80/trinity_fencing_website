# Updating the Committee

> You do not need to understand the website code to follow these instructions. Everything you need to do is in the Google Sheet.

The committee section is managed in the **DUFC Google Sheet**, in the tab called **Committee**. Update it at the start of each academic year when new officers are elected.

---

## How to Update the Committee

### Step 1 — Mark departing members as inactive

**Do not delete old rows.** Instead:

1. Open the **DUFC Google Sheet → Committee tab**
2. For each departing committee member, find their row
3. In column **G (active)**, change `TRUE` to `FALSE`
4. They will no longer appear on the website but their record is preserved

### Step 2 — Add incoming committee members

1. Scroll to the first empty row in the **Committee** tab
2. Fill in each column (see the column guide below)
3. The website will rebuild automatically in approximately 60 seconds

---

## Column Guide

| Column | What to enter | Example |
|---|---|---|
| **A — name** | Full name | `Liam Zone` |
| **B — role** | Committee role | `Club Captain` |
| **C — email** | Contact email (optional — only show if the person is happy to be contacted publicly) | `lzone@tcd.ie` |
| **D — bio** | One or two sentences about the person (optional) | `Liam has fenced sabre for 4 years...` |
| **E — photo_url** | Google Drive link to a headshot photo (optional — see photo instructions below) | `https://drive.google.com/file/d/...` |
| **F — display_order** | A number controlling the display order (lower = appears first) | `1` |
| **G — active** | `TRUE` to show on site, `FALSE` to hide | `TRUE` |

### Recommended display order

| Order | Role |
|---|---|
| 1 | Club Captain |
| 2 | Women's Captain |
| 3 | Men's Captain |
| 4 | Secretary |
| 5 | Treasurer |
| 6 | PRO |
| 7 | Equipment Officer |
| 8 | Social Secretary |
| 9 | Safety Officer |
| 10 | Fresher's Rep |

---

## Adding a Headshot Photo

1. Upload the headshot to **Google Drive** (a square crop works best)
2. Right-click the photo → **Share** → change "Restricted" to **"Anyone with the link"**
3. Click **Copy link**
4. Paste the link into column **E** of the committee member's row

If no photo is provided, the website automatically shows a placeholder with the person's initials on a red background.

---

## Updating the Coach

Coach details are in the **Coach** tab of the same Google Sheet. The columns are:

| Column | Description |
|---|---|
| A — name | Coach's full name |
| B — title | e.g. `Head Coach` |
| C — bio | Bio text (up to 300 characters) |
| D — photo_url | Google Drive link to a headshot |
| E — qualifications | e.g. `FIE Level 3 Coach` |

Each populated row is displayed on the website. To add another coach, add a new row in this tab.
